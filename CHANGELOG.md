# Changelog

Todos los cambios relevantes de ControlHub se documentarán en este archivo.

El formato sigue una estructura inspirada en Keep a Changelog.

## [Unreleased]

### Añadido

- Consolidación de la arquitectura técnica de V1.
- Esqueleto inicial de frontend, backend, tests, scripts y GitHub Actions CI.
- Definición del stack, seguridad, panel de administración, auditoría, testing y CI.
- Definición inicial del propósito y principios de ControlHub.
- Documentación inicial de arquitectura, roadmap, desarrollo, estado y decisiones.

### Cambiado

- El estado del proyecto pasa de diseño técnico inicial a arquitectura técnica consolidada.
- El proyecto pasa a disponer de una base ejecutable mínima, sin funcionalidades de negocio todavía.
- La V1 incorpora explícitamente administración, usuarios, roles/permisos, secretos y auditoría.
