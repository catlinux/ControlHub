# Roadmap

Este roadmap es orientativo. Las funcionalidades futuras no se consideran obligatorias hasta que exista una necesidad concreta.

## V1 — Base funcional

Objetivo: disponer de un centro de control personal funcional y sólido.

### Incluido

- Dashboard
- Categorías
- Recursos
- Tarjetas de recursos
- Búsqueda
- Tags
- Favoritos
- URLs
- Información SSH
- Apertura de recursos
- Copia de comandos SSH
- Estado básico de recursos cuando sea viable
- Autenticación
- Interfaz responsive
- Experiencia móvil cuidada

### No incluido inicialmente

- Ejecución remota arbitraria
- Monitorización avanzada
- Integraciones externas complejas
- Sistema avanzado de roles
- Automatizaciones complejas

## V2 — Supervisión

Posibles funcionalidades:

- Monitorización
- Estado de servicios
- Comprobación SSL
- Información de backups
- Inventario de infraestructura
- Documentación asociada

## V3 — Integraciones y acciones

Posibles funcionalidades:

- Integración con GitHub
- Integración con sistemas de backup
- Monitorización avanzada
- Notificaciones
- API pública o privada
- Roles y permisos avanzados
- Acciones remotas controladas

Las fases podrán modificarse según las necesidades reales del proyecto.
